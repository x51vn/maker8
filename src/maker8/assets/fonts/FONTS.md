# Bundled Font Assets

## Google Roboto (Variable)

- **File**: `google/roboto/Roboto.ttf`
- **Type**: Variable font (axes: Weight 100–900, Width 75–100)
- **Source**: https://github.com/google/fonts/tree/main/ofl/roboto
- **License**: Apache License 2.0 (see https://github.com/google/fonts/blob/main/ofl/roboto/LICENSE.txt)
- **SHA-256**: `d7598e12c5dbef095ff8272cfc55da0250bd07fbdecbac8a530b9b277872a134`
- **Why Roboto**: Full Vietnamese glyph coverage, clean readability on both portrait and landscape video, widely adopted, permissive license.

### Weight mapping

| Alias | Variation axis value |
|---|---|
| `font:roboto:regular` | Weight=400, Width=100 |
| `font:roboto:bold` | Weight=700, Width=100 |

### Backward compatibility

| Legacy alias | Maps to |
|---|---|
| `font:inter:regular` | `font:roboto:regular` |
| `font:inter:bold` | `font:roboto:bold` |
